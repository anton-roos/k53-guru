# K53 Learner's Licence — Test Structure (per code)

> **Source & confidence.** The figures below reflect the CLLT (Computerised Learner's Licence Testing) description provided by the project owner: eNaTIS-connected touchscreen terminals, biometric login, a bank of 1,200+ official NaTIS questions drawn at random, and three independent cut-off sections. Counts are **official ranges**, not fixed numbers. **High confidence on structure and pass marks; the exact per-sitting count varies within the stated range.** Confirm the final ranges and the time limit against a live DLTC/CLLT terminal before relying on them. The engine reads these from config, not hardcode (per SPEC constraint), so any adjustment is a data change.

## Sections (three independent cut-offs)

All three must be passed individually; failing one fails that code.

| Section | Axis | Notes |
| --- | --- | --- |
| Rules of the Road | shared | Right of way, speed limits, overtaking, parking, alcohol limits. Answered once in a combination |
| Road Traffic Signs & Markings | shared | Regulatory, warning, guidance signs and road markings. Answered once in a combination |
| Vehicle Controls | code-specific | Dashboard indicators, pedals/handlebars, gears, brakes. A separate module per selected code |

## Per-code question counts and pass marks (official ranges)

| Section | Questions | Pass |
| --- | --- | --- |
| Rules of the Road | 28–30 | 22 correct |
| Road Traffic Signs & Markings | 28–30 | 23 correct |
| Vehicle Controls | 8–12 | 6 of 8, or 10 of 12 |

Vehicle Controls content differs by code (e.g. motorcycle: handlebar levers, throttle, front/rear brake separation, foot gear peg, kill switch; heavy vehicle: three foot pedals, manual gearshift, air/parking brake, dashboard instruments).

## Combination sittings (per-code, independent grading)

A combination is a single booking covering two categories — **not** two separate test dates. Only motorcycle-plus-a-four-wheeler is offered:

- **Code 1 + Code 2** (motorcycle + light motor vehicle ≤ 3,500 kg)
- **Code 1 + Code 3** (motorcycle + heavy motor vehicle > 3,500 kg; Code 3 also covers light)
- **Code 2 + Code 3 is not offered** (redundant — Code 3 already permits light and heavy). There is no all-three sitting.

Delivery and grading:

- **Shared knowledge answered once:** the Rules of the Road and Road Traffic Signs sections are common and taken a single time.
- **Separate control modules:** a Vehicle Controls module per category (e.g. motorcycle controls *and* heavy-vehicle controls in a Code 1 + Code 3 sitting).
- **Independent per-code grading:** each code passes or fails on its own. **Partial pass** is possible — pass Code 1 but fail Code 3 and you keep the Code 1 licence and re-write only Code 3.
- **Re-testing:** only the failed code is re-booked and re-written.
- **Validity:** each issued endorsement is valid 24 months from date of issue.
